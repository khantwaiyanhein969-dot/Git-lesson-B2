   HTML (HyperText Markup Language) အကြောင်း မိတ်ဆက်
HTML ဆိုတာ ဘာလဲ?
HTML ၏ အရှည်ကောက်မှာ HyperText Markup Language ဖြစ်ပါသည်။ ၎င်းသည် ဝဘ်ဆိုက် (Website) များနှင့် ဝဘ်စာမျက်နှာ (Web Page) များကို တည်ဆောက်ရာတွင် အသုံးပြုသည့် အခြေခံအကျဆုံး ဘာသာစကားတစ်ခု ဖြစ်ပါသည်။ HTML သည် Programming Language တစ်ခု မဟုတ်ဘဲ ဝဘ်စာမျက်နှာပေါ်ရှိ စာသားများ၊ ပုံများ၊ ဗီဒီယိုများနှင့် လင့်ခ် (Link) များကို စနစ်တကျ နေရာချထားပေးသည့် Markup Language တစ်ခု ဖြစ်ပါသည်။

HTML ၏ အဓိက လုပ်ဆောင်ချက်များ

ဖွဲ့စည်းပုံ တည်ဆောက်ခြင်း (Structure): ဝဘ်စာမျက်နှာတစ်ခု၏ အရိုးအဆစ် (ဥပမာ - ခေါင်းစဉ်၊ စာပိုဒ်၊ ဇယားကွက်) များကို သတ်မှတ်ပေးပါသည်။

ချိတ်ဆက်ပေးခြင်း (Hypertext): စာမျက်နှာတစ်ခုနှင့် တစ်ခုကြား အလွယ်တကူ ကူးပြောင်းနိုင်ရန် Link များ ဖန်တီးပေးပါသည်။

မာလ်တီမီဒီယာ ထည့်သွင်းခြင်း (Multimedia): ဝဘ်ဆိုက်အတွင်း ရုပ်ပုံများ၊ အသံဖိုင်များနှင့် ဗီဒီယိုများကို ထည့်သွင်းပြသနိုင်ပါသည်။

အခြားနည်းပညာများနှင့် တွဲဖက်အသုံးပြုပုံ
ခေတ်မီဝဘ်ဆိုက်တစ်ခု ပြည့်စုံစေရန် HTML ကို အောက်ပါနည်းပညာနှစ်ခုနှင့် တွဲဖက်အသုံးပြုရပါသည်-

HTML: ဝဘ်ဆိုက်၏ အခြေခံဖွဲ့စည်းပုံ (Structure) ကို တည်ဆောက်ပေးသည်။

CSS (Cascading Style Sheets): ဝဘ်ဆိုက်ကို လှပစေရန် အရောင်၊ ဒီဇိုင်းနှင့် စာလုံးပုံစံ (Styling) များကို အလှဆင်ပေးသည်။

JavaScript: ဝဘ်ဆိုက်ကို အသက်ဝင်စေရန်နှင့် ခလုတ်နှိပ်သည့်အခါ တုံ့ပြန်မှုများ (Interactivity) လုပ်ဆောင်နိုင်ရန် ထိန်းချုပ်ပေးသည်။

ဘာကြောင့် HTML ကို လေ့လာသင့်သလဲ?

သင်ယူရန် လွယ်ကူပြီး နားလည်ရလွယ်ကူခြင်း။

မည်သည့် Web Browser (Chrome, Brave, Safari စသည်) တွင်မဆို အလုပ်လုပ်နိုင်ခြင်း။

Web Development လောကသို့ စတင်ဝင်ရောက်သူတိုင်း မဖြစ်မနေ တတ်မြောက်ထားရမည့် အခြေခံအုတ်မြစ်ဖြစ်ခြင်း။

GitHub ပေါ်တင်ရန် အကြံပြုချက်

ဤစာသားကို GitHub Repository ထဲရှိ README.md ဖိုင်ထဲတွင် ထည့်သွင်းပြီး တင်နိုင်ပါသည်။

အကယ်၍ Assignment အတွက် Document ဖိုင်အနေဖြင့် တင်ရမည်ဆိုပါက Microsoft Word (.docx) သို့မဟုတ် PDF ဖိုင်အဖြစ် ပြောင်းလဲပြီး Repository ထဲသို့ Upload တင်နိုင်ပါသည်။
